# Product image library

Use one folder per product family:

- `planetary-gearbox/` for planetary gearbox images
- `stepper-motor/` for stepper motor images

Recommended formats:

- WebP for website product photos
- PNG for transparent product cutouts
- SVG for technical diagrams and line drawings

Recommended naming:

- `pg28-front.webp`
- `pg42-front.webp`
- `pg42-side.webp`
- `nema-17-front.webp`
- `nema-23-front.webp`
- `nema-23-side.webp`

Keep product images at a consistent angle, background and aspect ratio where possible.
